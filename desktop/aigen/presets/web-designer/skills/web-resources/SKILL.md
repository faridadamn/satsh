# Sumber web gratis

Selalu sesuaikan sama DESIGN.md — sumber luar itu bahan, bukan arahan. Cek lisensi sebelum nyalin kode. Buka pakai browser_open, lihat pakai browser_look.

## Generator DESIGN.md
- designmd.co
- context.dev (bagian free tools)
- design.dev (bagian AI design md)

## Library UI / komponen (langsung salin kode)
- uiverse.io — komponen kecil (tombol, toggle, loader, kartu), banyak gaya
- transitions.dev — transisi & animasi halaman
- beautifului.dev — komponen siap pakai
- motion-primitives.com — komponen motion (React)
- ui-layouts.com — layout & blok halaman

## Generator background animasi
- neat.firecms.co — gradien animasi
- feralui.dev (gradients)
- patterncraft.store — pola/pattern

## Catatan antislop
- Background gradien/orb di hero = salah satu "tell" AI slop. Pakai cuma kalau ada fungsi & sesuai DESIGN.md (R-01).
- Jangan numpuk komponen dari banyak sumber dengan gaya beda — konsistensi > koleksi.
